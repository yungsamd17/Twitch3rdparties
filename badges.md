## Adding a new language

1. Pick the language's brand colour as a 6-digit hex code, without the `#`.
2. Find the logo name on [simpleicons.org](https://simpleicons.org). If there is no logo, leave out `&logo=...&logoColor=...`.
3. Use this format:

```markdown
![Name](https://img.shields.io/badge/-Name-RRGGBB?style=flat&logo=logoname&logoColor=white)
```

Use `logoColor=black` on light backgrounds such as JavaScript's yellow.
