# Discontinued and Abandoned Twitch Projects

Projects that are archived, discontinued, or have had no meaningful development for a long time. They are kept here for reference, so people can see what existed, where it stopped, and what to use instead.

An entry qualifies here if it is archived, if its last commit or release is about six years old or more, or if it has been abandoned with no progress for years. Check the project's repository for the latest activity before adding or changing an entry.

Dates below are from the pages checked for this list. Where a date could not be confirmed, the entry says so. For active projects, see the main [README](README.md).

## bttv-android

- **Type:** Mod of the official Twitch Android app adding BTTV, FFZ, and 7TV emotes
- **Where:** [bttv-android/bttv](https://github.com/bttv-android/bttv)
- **State:** Patches target Twitch 19.0.1 only and are not updated for newer Twitch versions. The repository is still public.
- **Last activity:** Last update Dec 27, 2024 (latest release v0.43.2-beta)
- **Alternatives:** [DankChat](https://github.com/flex3r/dankchat) and [Frosty](https://github.com/tommyxchow/frosty) for emotes in chat, or [Morphe patch sources](README.md#morphe-patch-sources-android) for patched official-app builds

## Pocket Plays for Twitch

- **Type:** Original open-source, ad-free Twitch player for Android
- **Where:** [SebastianRask/Pocket-Plays-for-Twitch](https://github.com/SebastianRask/Pocket-Plays-for-Twitch). The app was listed on Google Play. Check the current listing before relying on it.
- **State:** No longer developed by its original author. The project was forked into [Twire](https://github.com/twireapp/Twire), which is still maintained. No archive notice was found, and the repository is still public.
- **Last activity:** Last commit seen Aug 27, 2018. The newest open issue was opened Jul 2022 and has no reply in the pages checked.
- **Alternatives:** [Twire](https://github.com/twireapp/Twire)

## ReVanced Twitch patches

- **Type:** ReVanced patches for the official Twitch app, including ad blocking
- **Where:** [ReVanced/revanced-patches](https://github.com/ReVanced/revanced-patches) (project site: [revanced.app](https://revanced.app/))
- **State:** The main ReVanced patch repository is still active, but Twitch builds stopped at older versions. The Twitch patches were pinned to Twitch 14.x, and the latest Twitch build I found in ReVanced builds was 16.9.1. Current Twitch versions are not supported. Morphe is now the active successor for patching Twitch.
- **Last activity:** The main ReVanced repository was last released Mar 18, 2026. The most recent Twitch-specific change I found was an `auto-claim-channel-points` patch added around late 2023. The exact date could not be confirmed.
- **Alternatives:** [Morphe patch sources](README.md#morphe-patch-sources-android)

## frosty-swiftui

- **Type:** Experimental native iOS Twitch client in SwiftUI by the Frosty author
- **Where:** [tommyxchow/frosty-swiftui](https://github.com/tommyxchow/frosty-swiftui)
- **State:** Archived by its owner on Sep 17, 2024. The repository is read-only. The author put it on hold to focus on the Flutter version of Frosty.
- **Last activity:** Last update Sep 15, 2021. This is about five years, so it is below the six-year guideline. It is listed because it is archived.
- **Alternatives:** [Frosty](https://apps.apple.com/us/app/frosty-for-twitch/id1603987585), the Flutter version by the same author

## Twineo

- **Type:** Privacy-focused alternative web front-end for Twitch
- **Where:** [CloudyyUw/twineo on Codeberg](https://codeberg.org/CloudyyUw/twineo)
- **State:** Archived on Aug 10, 2026. The repository is read-only. The reason was not stated in the pages checked.
- **Last activity:** Last commit Apr 2024 from an earlier check. The archived page did not show a last-commit date, so this could not be re-confirmed.
- **Alternatives:** None listed. Check the archived repository for any notice about successors.

## SafeTwitch

- **Type:** Privacy-respecting Twitch front-end with a Go backend
- **Where:** [SafeTwitch/safetwitch on Codeberg](https://codeberg.org/SafeTwitch/safetwitch). The backend is at [SafeTwitch/safetwitch-backend](https://codeberg.org/SafeTwitch/safetwitch-backend).
- **State:** The frontend repository was archived on Dec 24, 2025. It is read-only. The reason was not stated in the pages checked.
- **Last activity:** Last release v2.4.4 on Feb 19, 2024. A later tag v2.4.5 exists, but its date could not be confirmed. The backend's last commit was Feb 6, 2024.
- **Alternatives:** None listed. Check the repository for any notice about successors.
